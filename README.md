# China Tourism

A small static two-page site on tourism in China and its major cities, built by the Orchestrate Solutions team.

## Pages
- `index.html`: home page, overview of visiting China
- `pages/cities.html`: the major cities

## Layout
- `css/tokens.css` (Designer), `css/layout.css` (UI/UX), `css/site.css` (Lead Dev)
- `js/app.js` (Full-Stack), `js/nav.js` (UI/UX)
- `assets/`: original SVG illustrations

Plain HTML, CSS and JavaScript. No build step.
